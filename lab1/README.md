## Возможности классов

### Vector
- Получение координат концов
- Вычисление длины
- Сложение/вычитание (`+`, `-`, `+=`, `-=`)
- Векторное произведение (`*`, `*=`)
- Умножение и деление на скаляр (`*`, `/`)
- Косинус угла между векторами (`^`)
- Сравнение по длине (`>`, `>=`, `<`, `<=`, `==`, `!=`)
- Ввод/вывод через потоки (`<<`, `>>`)

### Polynomial
- Получение степени, доступ к коэффициентам (`[]`)
- Вычисление значения в точке (схема Горнера, `()`)
- Сложение, вычитание, умножение, деление (`+`, `-`, `*`, `/`)
- Сравнение (`==`, `!=`)
- Ввод/вывод через потоки (`<<`, `>>`)

## Сборка

Проект собирается из консоли через **CMake**. Убедись, что установлены:

- CMake ≥ 3.16
- Компилятор с поддержкой C++17 (GCC 9+, Clang 10+, MSVC 2019+)
- Ninja или Make

### Linux / macOS

```
cd lab1
cmake -S . -B build -DCMAKE_POLICY_VERSION_MINIMUM=3.5
cmake --build build
```

### Windows (PowerShell, MSYS2 / MinGW)

```
cd lab1
cmake "-DCMAKE_POLICY_VERSION_MINIMUM=3.5" -S . -B build
cmake --build build
```

### Windows (Visual Studio)

```
cd lab1
cmake -S . -B build -G "Visual Studio 17 2022"
cmake --build build --config Release
```

### Что собирается

После успешной сборки в папке `build/` появятся:

| Артефакт | Назначение |
|---|---|
| `lab1_app` (или `lab1_app.exe`) | Консольное меню для работы с классами |
| `lab1_tests` (или `lab1_tests.exe`) | Unit-тесты на базе UnitTest++ |
| `liblab1_lib.a` | Статическая библиотека с классами Vector и Polynomial |

### Примечание про `CMAKE_POLICY_VERSION_MINIMUM`

Флаг `-DCMAKE_POLICY_VERSION_MINIMUM=3.5` нужен из-за того, что библиотека UnitTest++ пока не обновила свой минимальный требуемый стандарт CMake для версий CMake 4.0+. Без него конфигурация завершится ошибкой на этапе загрузки UnitTest++.
